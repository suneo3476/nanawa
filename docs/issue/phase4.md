# フェーズ4: データ拡張と高度な最適化

## 目的
セトリの質を向上させるためのデータ拡張と高度な最適化機能を実装する。

## タスク
1. **追加データ収集と統合**
   - 人気度スコアの取得と統合（優先度：高）
   - 公式ライブでの演奏頻度データ収集（優先度：中）
   - 音響特性データの収集と活用（優先度：低）
   - 季節適合性の評価機能（優先度：低）

2. **高度なアルゴリズム最適化**
   - 知名度バランスの最適化（優先度：高）
   - キー・テンポの自然な遷移制御（優先度：中）
   - ムード変化の滑らかさ制御（優先度：低）
   - MC挿入ポイントの提案（優先度：低）

3. **パフォーマンス評価システム**
   - 過去の実際のセトリとの比較機能（優先度：中）
   - 生成セトリの品質評価メトリクス（優先度：中）
   - ユーザーフィードバック収集機能（優先度：中）

## 成果物
- 拡張データモデルと収集スクリプト
- 高度な最適化アルゴリズム
- 評価・フィードバックシステム

## テスト基準
- 知名度バランスの取れたセトリが生成されること
- キー・テンポの遷移が自然であること
- 評価メトリクスによるセトリ品質の定量化
