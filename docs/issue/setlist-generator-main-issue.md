# セトリジェネレータの実装

## 概要
aikoコピーバンド「七輪」用のセットリスト自動生成ツールを開発する。曲の長さやテンポなどのメタデータを活用し、制約条件に基づいて最適なセットリストを生成する機能を提供する。

## 背景と目的
- ライブの制約（演奏時間、観客層、練習期間）に合わせた曲選びを効率化
- 知名度やテンポなどのバランスが取れたセットリストの作成を支援
- 過去の七輪のライブ経験を活かした選曲を可能にする
- 演奏メンバーのスキルレベルに合わせた難易度調整を実現

## 機能要件

### 入力機能
- 総演奏時間の指定
- 必須曲・除外曲の指定
- 練習期間の指定
- テンポバランスの希望指定
- ライブの特性（客層など）の指定

### データ管理
- 楽曲の長さ（分:秒）情報の管理
- 楽曲のテンポ（BPM）情報の管理
- 楽曲の知名度・人気度情報の管理
- 楽曲の演奏難易度評価

### セトリ生成
- 時間的制約を満たすセットリスト生成
- テンポバランスを考慮した選曲
- 知名度分布を考慮した選曲
- 構成パターン（オープナー、クローザーなど）の適用
- MC挿入位置の提案

### 調整機能
- 生成されたセットリストの手動調整
- 曲の入れ替え機能
- 曲順の変更機能
- 選曲理由の表示
- セットリスト全体の統計情報表示

### UI/UX
- 直感的な入力インターフェース
- セットリスト結果のビジュアル表示
- モバイル対応レスポンシブデザイン

## 実装方針
閃光弾型アプローチを採用し、最低限の機能を持つエンドツーエンドの実装から始め、段階的に機能を拡充していく。

## 実装フェーズ
1. 基本インターフェースと最小データモデル構築
2. データ拡充と制約機能の実装
3. 構成パターンと調整機能の追加
4. データ拡張と高度な最適化機能実装
5. UIのポリッシュと文書化

## 成功基準
- 指定した時間内に収まるセットリストを生成できる
- 必須曲・除外曲の条件を反映したセットリストを生成できる
- テンポや知名度のバランスが取れたセットリストを生成できる
- 生成されたセットリストを手動で調整できる
- 直感的なUIで操作可能
- データ更新手順が文書化されている
