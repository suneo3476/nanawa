# フェーズ2: データ拡充と制約機能

## 目的
基本機能が動作することを確認した上で、データを拡充し、ユーザーが制約を指定できる機能を追加する。

## タスク
1. **Spotify API連携による基本データ収集**
   - API認証と連携の実装（優先度：必須）
   - 曲の長さとBPM情報の一括取得（優先度：必須）
   - 取得データと既存データの統合（優先度：必須）

2. **制約入力UI拡張**
   - 必須曲指定機能の追加（優先度：必須）
   - 除外曲指定機能の追加（優先度：必須）
   - テンポバランス指定UI（優先度：高）
   - 練習期間入力UI（優先度：高）

3. **制約充足アルゴリズム実装**
   - 必須曲を含むセトリ生成機能（優先度：必須）
   - 除外曲を避けるロジック（優先度：必須）
   - テンポバランスを考慮した選曲（優先度：高）
   - 演奏難易度の簡易評価と反映（優先度：高）

## 成果物
- Spotify APIからのデータ取得スクリプト
- 拡張された制約入力UI
- 制約を考慮したセトリ生成アルゴリズム

## テスト基準
- すべての楽曲データに長さとBPM情報が付加されていること
- 必須曲・除外曲の指定が正しく反映されること
- テンポバランスに応じた曲選択ができること
