# フェーズ1: 基本インターフェースと最小データモデル

## 目的
最低限の入力と出力を持つ「動く」インターフェースを作成し、基本データモデルを構築する。

## タスク
1. **基本UIスケルトン実装**
   - 入力部分（演奏時間、曲数）の最小UI実装（優先度：必須）
   - 結果表示部分のスケルトン作成（優先度：必須）
   - ページ構造とコンポーネント設計（優先度：必須）

2. **最小データモデル構築**
   - 既存songs.ymlに必須フィールドのみ追加（`durationSeconds`）（優先度：必須）
   - 手動で数曲分のデータ追加（完全自動化はまだ不要）（優先度：必須）
   - モデル読み込み機能の基本実装（優先度：必須）

3. **最小限のアルゴリズム実装**
   - 単純な曲選択ロジック（時間内に収まる曲をランダム選択）（優先度：必須）
   - 基本的な曲順生成（優先度：必須）
   - アルゴリズム-UI間の連携実装（優先度：必須）

## 成果物
- 基本動作する最小限のUI
- 手動拡張された最小データモデル
- 単純なセトリ生成機能

## テスト基準
- 入力UIから結果表示までの基本フローが動作すること
- 時間指定で適切な曲数が選ばれること
- 基本的なレスポンシブ動作の確認
