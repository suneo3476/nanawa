# フェーズ3: 構成パターンと調整機能

## 目的
セトリの構成パターンを導入し、ユーザーが結果を手動調整できる機能を実装する。

## タスク
1. **セトリ構成パターン実装**
   - オープナー適性評価ロジック（優先度：高）
   - 終盤盛り上げパターンの実装（優先度：高）
   - 全体的なフロー設計アルゴリズム（優先度：中）
   - パターン適用の制御機能（優先度：中）

2. **結果調整UI実装**
   - 曲順の入れ替え機能（優先度：必須）
   - 個別曲の差し替え機能（優先度：必須）
   - セトリ全体の再生成機能（優先度：高）
   - カスタマイズ状態の保存（優先度：中）

3. **メタデータ表示の拡充**
   - 曲ごとの詳細情報表示（優先度：高）
   - セトリ全体の統計表示（優先度：中）
   - 選曲理由の説明機能（優先度：中）

## 成果物
- セトリパターンアルゴリズム
- 結果調整インターフェース
- 拡張メタデータ表示

## テスト基準
- パターンに応じた構成を持つセトリが生成されること
- ユーザーが曲順や曲選択を調整できること
- 各曲の詳細情報と選曲理由が表示されること
